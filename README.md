Shopping Mall  | Premium E-Commerce Storefront
Aura ek modern, minimalist, aur responsive e-commerce landing page hai jise clean UI aur seamless user experience ke liye design kiya gaya hai. Ye project handcrafted leather accessories aur premium fragrances ko showcase karne ke liye banaya gaya hai.

🚀 Features
Responsive Design: Mobile, tablet, aur desktop par perfectly optimize hota hai.

Modern UI: "FinTech" inspired aesthetic ke sath clean white space aur gold accents ka use kiya gaya hai.

Interactive Shopping Cart: Real-time JavaScript cart counter jo bina page refresh kiye update hota hai.

Sticky Navigation: Scroll karte waqt bhi header hamesha top par rehta hai.

Hover Effects: Product cards par smooth animations aur transitions.

🛠️ Tech Stack
HTML5: Semantic structure ke liye.

CSS3: Custom styling aur Flexbox/Grid layouts ke liye.

JavaScript (Vanilla): Dynamic DOM manipulation aur cart logic ke liye.

Font Awesome: Professional icons ke liye.

📂 Project Structure

/Aura-Storefront
│
├── index.html    # Website ki main structure file
├── style.css     # Design aur layouts ki CSS file
└── script.js    # Interactivity aur cart functionality

⚙️ Installation & Usage
Aapko is project ko chalane ke liye kisi server ki zaroorat nahi hai. Bas in steps ko follow karen:

Is repository ko clone ya download karen.

Yaqeen kar len ke index.html, style.css, aur script.js ek hi folder mein hain.

index.html file par right-click karen aur apne kisi bhi browser (Chrome, Edge, Firefox) mein open karen.

Tip: Agar aap VS Code use kar rahe hain, toh behtar experience ke liye Live Server extension install kar ke "Go Live" par click karen.
